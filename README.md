# RE:VERSE — The World You Prompt

A browser game for the EVOX prompt competition.

## Run locally
Open `index.html` in Chrome/Edge/Firefox.

## Deploy with GitHub Pages
1. Create a new public GitHub repository, e.g. `reverse-prompt-game`.
2. Upload `index.html`.
3. Open Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the live URL in the Pages section.

Expected URL format:
https://YOUR-GITHUB-USERNAME.github.io/reverse-prompt-game/

## Controls
WASD / Arrow Keys.
Use the Reality Console to enter prompts.
